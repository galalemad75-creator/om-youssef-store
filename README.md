# متجر أم يوسف — Om Youssef Store 🛍️

متجر إلكتروني احترافي بالدفع عند الاستلام (COD) لمصر.

## 🚀 خطوات التشغيل

### 1. تثبيت المتطلبات
```bash
npm install
```

### 2. إعداد قاعدة البيانات
```bash
# قاعدة البيانات بتتعمل تلقائيًا أول ما تشغّل الموقع
```

### 3. تشغيل الموقع محليًا
```bash
npm run dev
```
الموقع هيشتغل على: http://localhost:3000

### 4. لوحة التحكم
- الرابط: http://localhost:3000/admin
- كلمة المرور الافتراضية: `omYoussef2024`
- ممكن تغيرها من صفحة الإعدادات

---

## 🌐 النشر على Vercel (مجانًا)

### الخطوة 1: إنشاء حساب Vercel
1. ادخل على https://vercel.com
2. سجّل دخول بحساب GitHub

### الخطوة 2: رفع المشروع على GitHub
1. اعمل repository جديد على GitHub
2. ارفع كل ملفات المشروع

### الخطوة 3: ربط Vercel بـ GitHub
1. في Vercel، اضغط "New Project"
2. اختار الـ repository اللي عملته
3. اضغط "Deploy"

### الخطوة 4: إعداد متغيرات البيئة
في إعدادات المشروع على Vercel، أضف:
- `DATABASE_URL` = `file:./prisma/dev.db`
- `JWT_SECRET` = (كلمة سر عشوائية طويلة)

## 📱 إعدادات المتجر

### من لوحة التحكم (http://localhost:3000/admin):
- **رقم الواتساب**: بتاع صاحب المتجر لإشعارات الطلبات
- **هامش الربح الافتراضي**: نسبة الربح اللي بتتطبق على كل منتج جديد
- **فرق السعر للغات التانية**: المبلغ المضاف فوق السعر العربي (افتراضي 500 جنيه)
- **صورة الهيدر**: الصورة الكبيرة في أعلى الصفحة الرئيسية

## 📂 هيسل المشروع
```
├── src/
│   ├── app/
│   │   ├── [locale]/      # الصفحات الرئيسية
│   │   ├── admin/         # لوحة التحكم
│   │   └── api/           # APIs
│   ├── components/        # المكونات
│   ├── contexts/          # سلة المشتريات
│   ├── i18n/              # الترجمات
│   └── lib/               # utilities
├── prisma/                # قاعدة البيانات
└── public/uploads/        # الصور المرفوعة
```

---

## ⚠️ ملاحظات مهمة
- الصور المرفوعة بتتخزن في `public/uploads/`
- على Vercel، الصور المرفوعة مش هتفضل موجودة بعد كل deploy (لأن Vercel serverless)
- للإنتاج الحقيقي، استخدم خدمة تخزين صور زي Cloudinary أو S3
- قاعدة البيانات SQLite مناسبة للبداية، لما المشروع يكبر ممكن تنقل لـ PostgreSQL
